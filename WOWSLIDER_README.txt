DIAMORA - WOWSlider integration

The homepage now uses the WOWSlider-style generated markup structure:
- engine1/style.css
- engine1/wowslider.js
- engine1/script.js
- data1/images/
- data1/tooltips/

The old #heroImage jQuery slider has been removed from the homepage.

IMPORTANT:
This package uses the documented WOWSlider HTML structure and local engine files, but it was not exported by the proprietary WOWSlider desktop publisher. The official WOWSlider documentation states that data1 and engine1 are normally generated by its Publish to folder process.
